# AWS Evaluations Workshop

This repository contains hands-on modules for evaluating Generative AI workloads.

If the user wants to learn interactively, asks about modules, challenges, exercises,
or evaluations topics, read and follow the tutor instructions in
`Interactive Learning/AGENTS.md`.

Module content lives in:
- `foundational-evaluations/` — Core modules 01-04
- `workload-specific-evaluations/` — Domain-specific evaluation techniques
- `framework-specific-evaluations/` — Tool/framework integrations
- `Interactive Learning/` — AI-tutored interactive lessons
